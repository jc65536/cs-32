The stack-based algorithm exhausts the possibilities in one direction before
trying the next direction. This behavior is due to the stack only being able to
see the last-added coordinates, so it keeps branching off of it until no further
path exists.

On the other hand, the queue-based algorithm pops all the nearest
neighbors before branching out further. This is because the queue pops from the
front, so the newly added neighbors aren't processed until later.
