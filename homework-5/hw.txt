Problem 2
a.

    struct Node {
        Node *parent;
        Node *left;
        Node *right;
        int value;
    };

b.

    void insert(Node *root, int val):
        if val < root's value:
            if root has a left child:
                insert(root's left child, val)
            else:
                construct a new node and set it as root's left child
                set root as the new node's parent
        else if val > root's value:
            if root has a right child:
                insert(root's right child, val)
            else:
                construct a new node and set it as root's right child
                set root as the new node's parent
